# 🍃 Loma — Student Academic Helper (Naruto Shippuden Theme)

Built with **React + Vite**, styled with **Tailwind CSS v4**, routed with **React Router**.
All data persists in the browser via `localStorage` — no backend required.

## Pages (Navbar)
1. **Test** — log upcoming tests & past scores, see countdowns and average score.
2. **Classes** — track upcoming classes (teacher, room, date, time), mark attended.
3. **Events** — mission board for future events & tasks (D-Rank → S-Rank).
4. **Expenses** — daily expense ledger + **Savings Target Projector**: set a monthly budget
   and savings goal, watch the chakra progress bar and get a safe per-day spend limit.
5. **About** — app info; footer states this webapp is made using **QWEN** as a test app.

## Run it
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```
